# Design Vision

Design a premium, enterprise-grade digital experience that reflects innovation, trust, intelligence, and global excellence.

The website should feel comparable to products from:

- Apple
- OpenAI
- Stripe
- Linear
- Vercel
- Notion
- Arc Browser

Avoid traditional education website aesthetics.

The experience should communicate confidence, professionalism, and modern technology.

---

# Design Principles

## 1. Minimalism

Every section should breathe.

Use whitespace generously.

Avoid clutter.

Every component must have a purpose.

---

## 2. Premium Experience

The website should feel expensive.

High-end typography.

Subtle gradients.

Soft shadows.

Glassmorphism only where necessary.

Large spacing.

Elegant transitions.

---

## 3. Modern Technology

The website should feel like an AI company instead of a university website.

Professional.

Clean.

Interactive.

Fast.

---

## 4. Consistency

Every component should follow the same spacing system.

Same border radius.

Same button system.

Same typography.

Same card style.

Same animation timing.

---
